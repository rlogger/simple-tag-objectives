Uncertainty-aware opponent modeling

A minimal scaffold for inferring hidden predator strategies online — before planners, before co-training, before SOTA claims.

opponent-modeling · MAPPO specialists · GRU-JEPA · eval probe · BC baseline

Problem

Infer the opponent’s objective from behavior

  • Predator type is hidden: capture / risk / curious
  • Prey must update a belief online from the trajectory so far
  • Part 1 = robust policy model of the opponent
  • Part 2 = planner that samples that model — deferred
Labels exist for evaluation only. The encoder is trained self-supervised.

Pipeline

Specialists → encode → evaluate → baseline BC

tag_objectives→ MAPPO ckpts→ rollouts→ GRU-JEPA→ eval probe→ π(a|s,z) baseline→ JSON manifest
  • Primary encoder: variable-length GRU-JEPA (unit-sphere, no VICReg)
  • Baselines: window JEPA, β-VAE
  • Ceiling: supervised oracle on the same features

What “uncertainty-aware” means

Soft belief over types — not a single frozen z

Target

  • Online belief bt over strategy types
  • Entropy rises when evidence is weak
  • Downstream: mixture π(a|s,bt)

Status today

  • Logistic probe = evaluation instrument
  • BC still conditions on point latent z
  • Mixture / sequential Bayes = next milestone
Do not train BC on probe posteriors — that leaks eval labels into the opponent model.

This week · foundation hardening

Make the experiment trustworthy before claiming results

  • Pad-masked GRU + unit-sphere JEPA + later-prefix targets
  • Capture-aware lengths — drop post-capture frozen frames from BC
  • Checkpoint-held-out splits — train-only encode / probe / GMM
  • Collapse diagnostics — across-episode std, effective rank
  • run_part1.py — reproducible JSON manifests (git SHA, pins, metrics)
These are prerequisites for numbers that mean something — not optional polish.

Metric protocol

What we will report (and what we won’t)

Report

  • Held-out probe ± survival-time control
  • GMM ARI + collapse diagnostics
  • ECE on held-out soft scores
  • BC: π(a|s) vs π(a|s,z) baseline
  • Mean ± std over ≥3 seeds

Not yet

  • SOTA / external superiority
  • “LayerNorm prevents collapse”
  • Bayesian posterior claims
  • Robustness to novel opponents
  • Belief-mixture BC as solved

Roadmap

Next milestones

  • 1. Belief-mixture BC — π(a|s,bt) = Σk bt(k) πk(a|s)
  • 2. Open-set / held-out objective + calibration
  • 3. Cross-play data (shared prey) to kill prey fingerprinting
  • 4. Then Part 2 planners on a trustworthy opponent model
Honest line: minimal Part 1 scaffold, experiment hardened so numbers won’t lie; sequential belief-conditioned opponent modeling is the next claim — not today’s.
